# 本地翻译页面

从项目根目录启动：

```powershell
python -m arxiv_translate.web_app
```

打开 <http://127.0.0.1:8765/>，上传 arXiv 论文 PDF，选择 DeepSeek Flash 或 OpenAI GPT-4o mini，输入对应 API Key 后开始翻译。页面会显示任务进度、预览生成的中文 PDF，并提供下载。

首次运行需要本地 MiKTeX/TeX Live、Perl、XeLaTeX、中文字体，以及能访问 arXiv 和所选模型 API 的网络。PDF 必须带有可识别的 arXiv **版本号**（如 `2511.02841v2`）；若 PDF 首页未标明版本，请将文件命名为 `2511.02841v2.pdf`。没有 LaTeX 源码、源码无法在本机编译、模型调用失败或中文编译失败时，任务会显示错误，不会假装生成 PDF。论文内容会发送给所选模型服务商，模型调用可能产生费用。

API Key 由本机服务接收，翻译期间临时提供给现有翻译模块；页面不会保存在浏览器存储中，服务不会写入任务文件或日志。任务进度仅保存在进程内存中，重启服务后不能从页面恢复旧任务；阶段二检查点和已生成的 PDF 仍留在项目目录。一次只运行一篇，以避免不同任务的密钥或输出互相干扰。

这个服务只监听 `127.0.0.1`，适合个人本机使用。**不要直接部署到公网或提供给不受信任的用户**：现有 LaTeX 编译方式不是完整沙箱；公网服务还需要身份认证、任务隔离、上传与源码安全审查、真正隔离的编译环境、HTTPS 和密钥管理。
