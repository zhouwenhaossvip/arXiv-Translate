# 本地翻译页面

从项目根目录启动：

```powershell
python -m arxiv_translate.web_app
```

打开 <http://127.0.0.1:8765/>，上传 arXiv 论文 PDF，从 DeepSeek Flash / V4 Pro 或 OpenAI GPT-4o Mini / GPT-4.1 Mini / GPT-4.1 / GPT-4o 中选择模型，输入对应服务商的 API Key 后开始翻译。页面会显示任务进度、预览生成的中文 PDF，并提供下载。模型是否可用取决于用户的 API 账户权限，调用会按服务商用量计费。

首次运行需要本地 MiKTeX/TeX Live、Perl、XeLaTeX、中文字体，以及能访问 arXiv 和所选模型 API 的网络。PDF 必须带有可识别的 arXiv **版本号**（如 `2511.02841v2`）；若 PDF 首页未标明版本，请将文件命名为 `2511.02841v2.pdf`。未识别到 arXiv 编号时会提示当前仅支持 arXiv 论文；找不到对应版本的可用 LaTeX 源码时，会提示核对编号、版本与来源。源码无法在本机编译、模型调用失败或中文编译失败时，任务也会显示错误，不会假装生成 PDF。论文内容会发送给所选模型服务商，模型调用可能产生费用。

API Key 由本机服务接收，翻译期间临时提供给现有翻译模块；提交后模型选择和 Key 会保留在当前页面，方便连续翻译，但不会写入浏览器存储、任务文件或日志。刷新或关闭页面后需重新输入。任务进度仅保存在进程内存中，重启服务后不能从页面恢复旧任务；阶段二检查点和已生成的 PDF 仍留在项目目录。一次只运行一篇，以避免不同任务的密钥或输出互相干扰。

这个服务只监听 `127.0.0.1`，适合个人本机使用。**不要直接部署到公网或提供给不受信任的用户**：现有 LaTeX 编译方式不是完整沙箱；公网服务还需要身份认证、任务隔离、上传与源码安全审查、真正隔离的编译环境、HTTPS 和密钥管理。
